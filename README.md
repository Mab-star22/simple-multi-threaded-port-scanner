# Cybersecurity & Python Utility Tools 🇿🇦

A collection of lightweight Python security tools built to apply concepts from my **IBM Cyber Security Fundamentals** badge and **Python (Basic & Intermediate)** certifications through NVIDIA DLI in Unstop.

---

## 📌 Project Summary

This project combines two core cybersecurity scripts into a practical toolset:

1. **Port Scanner (`port_scanner.py`) — Network Security**
   * Checks target IP addresses or websites (like `scanme.nmap.org`) for open network ports (e.g., SSH, HTTP, HTTPS).
   * Identifies active network services to assess system exposure.

2. **Password Auditor & Cipher (`password_checker.py`) — Data Protection**
   * Audits user passwords against security standards (length, numbers, uppercase letters).
   * Encrypts plain text using a Caesar cipher algorithm to demonstrate fundamental cryptography principles.

---

## 🚀 How to Run

```bash
# To run the Port Scanner:
python port_scanner.py

# To run the Password Auditor:
python password_checker.py
```
